# Воспроизведение сценариев

Запуск: docker compose up --build. Открыть http://localhost:3000. Пароль всех аккаунтов demo1234. Поля финансов оставить пустыми для получения из моков. Срок 12 месяцев, цель любая непустая.

| Аккаунт | Продукт и сумма | Результат |
|---|---|---|
| client_fast | Оборотный, 1 500 000 ₽ | 100 баллов, APPROVED |
| client_counter | Оборотный, 10 000 000 ₽ | 100 баллов, COUNTER_OFFER на 6 000 000 ₽ |
| client_manual | Оборотный, 1 500 000 ₽ | 50 баллов, MANUAL_REVIEW |
| client_info | Оборотный, 1 500 000 ₽ | NEEDS_INFO, запрос годовой выручки |
| client_reject | Оборотный, 1 500 000 ₽ | REJECTED, просрочка 120 дней |
| client_timeout | Оборотный, 1 500 000 ₽ | Недоступен БКИ, MANUAL_REVIEW |

Одобрение/контроффер: принять предложение, ввести 123456, нажать «Подписать и получить кредит · симуляция». Результат ISSUED, сумма и время выдачи. Можно отказаться от предложения вместо принятия.

Ручная проверка: запомнить номер, выйти, войти underwriter. Открыть заявку, увидеть источники, баллы и факторы. Выбрать одобрение, написать обязательный комментарий и сохранить. Войти исходным клиентом, открыть ту же заявку и принять оффер.

Дозапрос: в карточке client_info ввести годовую выручку 12 000 000 ₽, отправить данные. Новый скоринг даёт APPROVED, пустой ответ ФНС не затирает выручку. Поля, которых банк не запрашивал, API не принимает.

Черновик: заполнить часть анкеты, дождаться «Черновик сохранён», обновить страницу. Восстанавливаются поля и шаг. Чужая компания получает 404 на эту заявку; клиент получает 403 на панель банка.

Проверки команд: одинаковый ключ accept/sign/missing-info и тело возвращает исходный ответ, другое тело даёт 409. Конкурентные повторы не создают вторую проверку/оффер/выдачу; подпись до принятия оффера запрещена. Тесты идут на PostgreSQL, HTTP-интеграционные сценарии — на настоящем WireMock.

Команды: docker compose --profile test run --build --rm tests; в frontend: npm ci, npm run typecheck, npm run build, npm run test:e2e. Playwright использует установленный Google Chrome; для другого браузера изменить channel в playwright.config.ts. WEB_URL переопределяет адрес стенда.
