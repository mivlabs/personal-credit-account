# Исходные материалы

Артефакты проектирования лежат в [`../design/`](../design/): principles.md, bpmn-to-be.bpmn, c4/, data-dictionary.md, data-model.drawio, use-case-*.png и модели данных в PNG. Отдельный официальный кейс и уточнения организаторов в репозитории не обнаружены. При их появлении решения следует сверить с ними; текущая приоритизация и расхождения — в ../assumptions.md.
