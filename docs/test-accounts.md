# Тестовые аккаунты

Все данные синтетические. Пароль у всех аккаунтов: **`demo1234`**. Вход: `POST /api/v1/auth/login`.

Аккаунты и компании создаёт seed при старте контейнера `api` (после миграций). Он идемпотентен: повторный запуск
ничего не дублирует и не перезаписывает существующих пользователей и компании.

> **ИНН закреплены.** Под них Миша делает стабы WireMock (ЕГРЮЛ / ФНС / БКИ), менять их без договорённости нельзя.

## Ожидаемые исходы

Цифры условные: итоговые значения зависят от скоринг-карты и порогов (политика: балл ≥ 70 — авто, 40–69 — ручная
проверка, < 40 — отказ).

| Логин | Заявка для прогона | Внешние данные (что отдают моки) | Ожидаемый путь |
|---|---|---|---|
| `client_fast` | Оборудование, 1,5 млн ₽, 24 мес. | ЕГРЮЛ: действует; ФНС: отчётность есть, высокая выручка; БКИ: просрочек нет | `APPROVED` → принять → подписать → `ISSUED` |
| `client_counter` | Оборотный кредит, 10 млн ₽ | Хорошая история, но выручка не покрывает запрошенную сумму | Балл ≥ 70, сумма выше лимита → `COUNTER_OFFER` (около 6 млн ₽) → принять |
| `client_manual` | Оборотный кредит, 3 млн ₽ | Компании 9 мес., выручка хорошая | Балл 40–69 → `MANUAL_REVIEW` → решение андеррайтера с комментарием |
| `client_info` | Оборотный кредит, 2 млн ₽ | ФНС: нет отчётности (нет выручки за год) | `NEEDS_INFO` (запрос выручки) → клиент дозаполняет → повторный скоринг |
| `client_reject` | Оборотный кредит, 1 млн ₽ | БКИ: просрочка 120 дней | Стоп-фактор → `REJECTED` с причиной простым языком |
| `client_timeout` | Овердрафт, 500 тыс. ₽ | БКИ возвращает синтетический 503 | `EXTERNAL_CHECK → SCORING → MANUAL_REVIEW`, причина недоступности БКИ |

Настоящий таймаут источника: ИНН `7701000099` (отдельного логина нет, используется в тесте `test_slow_source_is_timeout_within_budget`): БКИ отвечает с задержкой 2 с, опрос укладывается в бюджет `EXTERNAL_CHECKS_BUDGET_SECONDS` (по умолчанию 3 с), источник получает статус `TIMEOUT`.
